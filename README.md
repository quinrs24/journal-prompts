# Journal Prompts — Review past answers when saving

Upload the six files in this ZIP to the root of your existing GitHub Pages repository, replacing the matching files. Wait for deployment, then close and reopen or refresh the app.

- Session cards no longer display past-answer buttons or history highlights. Write all your responses first.
- Choose **Save session to Google Doc**. If any question has previous saved answers, one dialog asks whether you would like to see them.
- **Yes, view past answers** shows all matching answers together, grouped by question and dated newest first. Choose **Save session to Google Doc** when finished reviewing.
- **No, save now** skips the review and saves immediately.
- **Back to writing** or Escape cancels without saving or discarding your drafts.
- If none of the questions has past answers, saving proceeds directly. If the history lookup fails, you can save without reviewing or return to writing.
- Earlier answers never appear automatically. Repeated questions in the same session share one review group. On This Day retains its separate optional View past entries button.

Free write, shuffled library, Favorites, skip cues, mobile scrolling, and existing Google Docs/Sheets saving remain included.

Validation: JavaScript syntax and behavior checks with simulated Google responses. Real Google authorization and physical phone gestures were not tested here.
